# HTML report format

**Standard** shareable HTML sibling to the markdown brief. Emit on every full
`/whathappened` run unless the user explicitly opts out (`markdown only` /
`no HTML`).

## Storage

Reports live in a **sibling folder** next to the skill repo (not packaged inside
the skill):

```text
../whathappened-reports/whathappened-{topic-slug}-{YYYYMMDD[-HHMM]}.html
```

Create `whathappened-reports/` if it does not exist. Prefer reusing that folder
when it already has prior reports (CSS source of truth). User-named paths
override the default.

For personal audiences, include an audience token in the slug when useful:

```text
whathappened-software-factory-list-20260730.html
whathappened-kimi-k3-following-20260718.html
```

Reuse CSS and card layout from an existing report in that folder (same
`:root` tokens, `.mast`, `.card`, `.receipts`, opinion table, print rules).
Do not invent a new visual system.

## When to emit

**Always** after Step 8 synthesis, except:

- User said `markdown only` / `no HTML`
- Run aborted before a full brief (no topic, X tools missing, personal roster gate)

Always send the markdown brief in chat first (or alongside). HTML is not a
substitute for the chat brief. Tell the user the file path in one line; do not
paste the full HTML into chat.

## Mast meta pills (required)

| Pill | Content |
|------|---------|
| Window | Human window string |
| Mode | `Breaking` / `Same-day` / `Story` / `Background` - use class `mode-{Mode}` |
| As of | UTC stamp |
| Confidence | high / medium / thin (+ short qualifier) — class `conf-{level}` |
| Sample | ~N posts · lanes · threads |

### Audience pills (Global vs personal)

**Global X** (default reports may omit Audience pills, or show one global pill):

```html
<span class="pill audience-global"><strong>Audience</strong>&nbsp;Global X</span>
```

**Following** (prefer or strict):

```html
<span class="pill audience-following"><strong>Audience</strong>&nbsp;Following · prefer · N accounts</span>
<span class="pill audience-following"><strong>Coverage</strong>&nbsp;sampled · ~P posts from M roster authors</span>
```

**X List** (prefer or strict) — **required** when the brief used a List:

```html
<span class="pill audience-list"><strong>Audience</strong>&nbsp;X List {id or label} · prefer · N members</span>
<span class="pill audience-list"><strong>Coverage</strong>&nbsp;sampled · ~P posts from M roster authors</span>
```

Kicker for personal scopes:

```html
<p class="kicker">/whathappened · X-first briefing · personal audience</p>
```

## Sections (same order as markdown)

1. What happened — quotes with `<blockquote class="quote">` + `<cite>`
2. Where the conversation is — `.frames` list
3. **Public opinion map** (Global) or **Audience opinion map** (Following / List)
4. The live debates — `.debate` blocks
5. Notable posts (receipts) — `.receipts` list
6. Gaps / caveats

### List / Following receipt rules

- Roster-verified receipts: normal card; optional `<span class="badge-list">list</span>` or `following`
- Prefer mode global context (kept for event framing): `class="global-context"` on
  `<li>` plus `<span class="badge-global">global</span>`
- Strict mode: do **not** put non-roster authors in the opinion table or as
  audience receipts; official/origin may still appear under What happened only

Footer should restate audience, e.g.:

```html
Generated by /whathappened · X List prefer · list {id} · N members · {date} UTC
```
